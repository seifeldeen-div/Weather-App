# WeatherPro - Modern Weather Mobile App
A premium, futuristic weather application with a dark purple gradient theme and glassmorphism design.

##  Features

### Screens
1. **Splash Screen** - Animated weather logo with smooth transitions
2. **Home Screen** - Current weather, hourly forecast, and weather details
3. **Forecast Screen** - 7-day detailed weather forecast
4. **Search Screen** - Real-time city search with weather preview
5. **Settings Screen** - Dark mode, temperature units, notifications

### Design
- Dark purple/blue gradient theme
- Glassmorphism effects with backdrop blur
- Smooth animations using Motion
- iPhone 14 Pro frame size (393x852px)
- Premium mobile app aesthetic

### Functionality
- Weather data by city
- Real-time search with suggestions
- Temperature unit toggle (Celsius/Fahrenheit)
- Dark mode support
- Responsive bottom navigation
- Loading, error, and empty states

### Development
The app currently runs with mock data. To enable real API integration:

1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Add the key to your `.env` file
3. Uncomment the API calls in `src/services/weatherApi.ts`
